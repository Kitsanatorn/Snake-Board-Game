# สวนเบญจกิตติ · บันไดงูหรรษา (Benjakitti Snakes & Ladders)

เกมกระดานบันไดงูธีมสวนป่าเบญจกิตติ กรุงเทพฯ สำหรับ 1-4 ผู้เล่น

## 🎮 โหมดการเล่น (Game Modes)
1. **เล่นกับบอท (Solo vs Bot)**: เล่นคนเดียว ประลองฝีมือกับบอทเจ้าถิ่น (1-3 บอท)
2. **Multiplayer แบบ Kahoot PIN**:
   - **ใส่รหัสห้อง (Join PIN)**: ใส่รหัส Game PIN 6 หลัก + ชื่อเล่น + เลือกตัวละคร แล้วลุยได้เลย
   - **สร้างห้อง (Host Game)**: สร้างห้องรับรหัส Game PIN ส่งให้เพื่อนเข้าเล่นในห้องรอ เมื่อพร้อมแล้วกดเริ่มเกม
   - **เล่นเครื่องเดียวกัน (Pass & Play)**: 2-4 คน ผลัดกันทอยลูกเต๋าบนจอเดียว

## 🚀 วิธีเปิดเล่น
- เปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที
- หรือรันผ่านเว็บเซิร์ฟเวอร์: `npx serve .` แล้วเปิด `http://localhost:3000`
